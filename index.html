This privacy policy governs your use of the software application Ludo Star Master ("Application") for mobile devices, which was created by Aqib Tech. The Application is a high-fidelity Ludo championship board game featuring local multiplayer (Pass 'N Play), gameplay against smart computer players, global & in-game chats, multiplayer matchmaking rooms, rewards management, and aesthetic customizable themes.

1. Information Collection and Use

The Application collects and stores limited user information to enable various interactive game features:

  • User Profile Data: Local nickname, custom avatars, level indicators, coins, gems, and win/loss records are safely stored locally using secure Android storage components (SQLite Room Database).
  • Gameplay & Matchmaking: Basic online identifiers are processed on our servers solely to match players in multiplayer custom lobby rooms. Chat messages sent in the global chat or in-game are processed in real-time to facilitate conversation.
  • Device Identification: Non-personally identifiable advertising and device IDs may be collected to support user statistics and render personalized/non-personalized advertisements.

  • Firebase Services: Used to support server operations, secure AI modules, real-time message relays, and crash reporting metrics. Firebase Privacy Policy
